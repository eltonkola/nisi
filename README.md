#NISI Launcher

This is a simple but powerful launcher for Android TVs.


# Run on a phone
To easily test the app on a phone, you can use scrcpy. Download it from https://github.com/Genymobile/scrcpy/releases
Then run it with the following command:
```
./scrcpy.exe --new-display=3840x2160 --start-app=com.eltonkola.nisi
```
This will start mirror the app on your computer with a 4k resolution. For tv inputs run https://github.com/eltonkola/Telekomanda on your computer..

Both apps need your phone to be adb connected/paired.
